# Consigne pour toute session Claude sur ce dépôt

Avant toute chose, lire `CENTRAL_TRANSMISSIONS_DEVIS.md` : c'est le point central du projet
(Cockpit Devis, Transmissions devis, Copilot portails mutuelles), avec l'architecture, ce qui est
en service, les archives et le journal des décisions.

Règles :
- Ne rien supprimer sans décision explicite du Dr : on archive et on le note dans le point central.
- Toute décision prise en session est ajoutée au « Journal des décisions » du point central, avec sa raison.
- Données patients : jamais de nom, NIR ou date de naissance dans les fichiers du dépôt ni dans les réponses.
- Le code de référence de l'app Transmissions est `apps-script/transmissions-devis-unique/`.
